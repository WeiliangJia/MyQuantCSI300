# 架构与数据契约

## 业务顺序

1. 数据运营：Tushare拉取、原始归档、标准化写库和质量检查。
2. 投研：按 `available_at` 查询点时数据，计算因子、IC和样本外诊断。
3. 组合管理：按周构建50只股票的目标权重，并约束行业、换手和跟踪误差。
4. 交易运营：下一交易日开盘模拟撮合，记录订单、拒单原因、持仓和净值。
5. 风控与报告：每日检查数据/仓位，周度输出相对基准的绩效与归因。

## 时间语义

- `trade_date`：市场发生交易的日期。
- `announcement_date`：披露公告日。
- `available_at`：本系统允许使用该记录的最早日期；财务数据不得早于公告日。
- `ingested_at`：本系统接收到数据的时间。

任何研究查询必须带 `as_of_date`，且仅返回 `available_at <= as_of_date` 的记录。

## PostgreSQL schema

`raw` 保存不可变下载元数据；`market` 保存标准化行情、成分和公司行动；`research` 保存因子和诊断；`portfolio` 保存目标权重与风险快照；`simulation` 保存订单、成交、持仓与净值；`ops` 保存质量检查与运行日志。
