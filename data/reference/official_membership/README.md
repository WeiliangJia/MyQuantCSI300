# 本地基准成分文件（不公开）

本目录中的实际基准名单、调样清单和采集目录均被 `.gitignore` 排除，只留在本机。公开仓库仅保留本说明和空白字段模板；项目与中证指数有限公司不存在授权、合作或背书关系。

要启动认证研究，创建一份不提交到公开仓库的 `csi300_baseline_YYYYMMDD.csv`：

```csv
ts_code,as_of_date
000001.SZ,2026-06-15
...
```

要求：

- 只能有一个 `as_of_date`，并且该日为官方成分生效日；
- 恰好 300 个唯一 `ts_code`；
- 该文件必须由中证官方历史成分数据或已归档的官方完整名单生成；
- 基准日期及以后所有调样事件都必须有已复核的官方 ADD/REMOVE 清单；
- 另需导入同期间每日 300 个官方基准权重，权重和约为 1，才能运行优化和回测。

使用方法：

```powershell
myquant rebuild-membership data/reference/official_membership/csi300_baseline_YYYYMMDD.csv YYYY-MM-DD YYYY-MM-DD
myquant certified-range --min-trading-days 60
```

认证通过前，因子、优化、撮合、成本和风控研究入口应保持阻止状态。
